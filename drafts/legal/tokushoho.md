## 公開前に確かめること

法律の専門家が確認した文面ではありません。次の点は、運営者が自分で確かめてください。

### 1. 氏名・住所・電話番号を載せないことについて

**法律**：個人事業者でも、氏名・住所・電話番号の表示が必要です。ただし、「請求があれば遅滞なく提供する」と広告に表示し、
**実際に遅滞なく提供できるようにしている**場合は、省略できます（特定商取引法 11条ただし書）。

- 根拠：消費者庁 特定商取引法ガイド「通信販売広告Q&A」Q15（氏名）・Q17（住所・電話番号）
  https://www.no-trouble.caa.go.jp/qa/advertising.html
- 同じページによると、「遅滞なく」とは、申込みを決める前に十分な余裕をもって提供されることです。
  つまり、**請求のメールが来たら、すぐに本名・現住所・連絡の取れる電話番号を返信する**必要があります。断ることはできません。
- 屋号・サイト名だけの表示は認められません（同 Q16）。開示するときは戸籍上の氏名です。
- 私書箱は住所になりません（同 Q19）。バーチャルオフィスの住所は、同 Q18 の3つの条件を満たすときだけ使えます。

**Stripe**：Stripe のヘルプは、個人事業主の場合、販売事業者名・所在地・電話番号は「請求があったら遅滞なく開示します」と
書くことで省略できる、としています。一方、**運営統括責任者とメールアドレスには、省略できるという記載がありません**。

- 根拠：Stripe ヘルプ「特定商取引法に基づく表記ページの作成と表示方法」
  https://support.stripe.com/questions/how-to-create-and-display-a-commerce-disclosure-page?locale=ja-JP
- したがって、氏名を出さない方針のままで Stripe の審査に通るかは**未検証**です。申請の前に、Stripe のサポートに
  「個人事業主で、運営統括責任者の氏名も、請求があれば遅滞なく開示する、という表記にできるか」を問い合わせてください。
  できない場合の選択肢：(a) 運営統括責任者の欄にだけ氏名を載せる、(b) B案をやめて note を続ける、(c) 法人や屋号の登記を検討する。
- Stripe は、ページの題名を「特定商取引法に基づく表記」（または「通信販売に関する表示事項」）にすること、必要な項目を
  1ページにまとめること、トップページや決済のページから行きやすい場所（フッターなど）にリンクを置くことを求めています（同じヘルプ）。
  このサイトでは、`content/tokushoho.md` を置くと、フッターにリンクが出ます。
- Stripe への申請フォームには、表記とは別に、本名・住所・電話番号を入力します。

### 2. 省略できない項目

消費者庁の表（https://www.no-trouble.caa.go.jp/what/mailorder/ ）では、販売価格を表示する場合、次の項目は省略できません。
この下書きには入れてあります。内容が実際と合っているかを確かめてください。

- 支払時期（前払いの場合）
- 2回以上続けて契約する場合の条件（＝月額制であること、金額、解約の方法）
- ソフトウェアの動作環境
- 特別な販売条件

### 3. 申込みの最終確認の画面

月額制のサービスは、申込みを確定する画面に、分量（期間）・価格・支払の時期と方法・提供時期・解約に関することを
表示する必要があります（特定商取引法 12条の6）。

- 根拠：消費者庁「通信販売」https://www.no-trouble.caa.go.jp/what/mailorder/ 、
  Stripe ヘルプ「2022年6月施行の改正特定商取引法におけるガイドライン」
  https://support.stripe.com/questions/guidelines-under-the-revised-specified-commercial-transactions-act-to-be-enforced-in-june-2022?locale=ja-JP
- このサイトの Workers は、Stripe の決済ページの支払いボタンの近くに「月額制・毎月自動で更新・解約の方法・この表記へのリンク」
  を出すようにしてあります（`worker/src/index.js` の `checkout`）。**実際の画面で、価格・毎月の請求・解約の方法が読めることを、
  テスト環境で自分の目で確かめてください**（`MIGRATION_B.md` の D）。足りるかどうかの判断は**未検証**です。
- Stripe のダッシュボードの「設定 → Checkout と Payment Links」で、返金・返品のポリシーを表示する設定があります（上の Stripe ヘルプ）。

### 4. 返金の方針

通信販売には、訪問販売のようなクーリング・オフの制度はありません。返品（解除）の扱いは、広告に書いた内容が適用されます
（消費者庁「通信販売」の「契約の申込みの撤回又は解除」）。この下書きは「返金しない。ただしサイトの不具合のときは返金する」
としています。方針を変えるときは、この欄と、Stripe の決済ページの表示の両方を直します。

### 5. 単品販売・法人プランを始めるとき

価格・支払時期・提供時期の欄に、その商品の行を足します（単品は「買い切り。自動更新なし」と書く）。
