擬似言語トレースドリル（以下「当サイト」）は、利用者の情報を次のとおり扱います。

制定日：【公開する日】

## 1. 運営者

当サイトは、個人が運営しています。運営者の氏名と住所は、ご本人からの求めがあれば、遅滞なくお答えします。
連絡先：【連絡用のメールアドレス】

## 2. 無料の練習問題・サンプル模試を使うとき

会員登録なしで使えます。名前やメールアドレスをうかがうことはありません。

### 端末への保存

次の情報を、お使いのブラウザの中（localStorage）に保存します。**当サイトのサーバーには送りません。**

- 練習形式と本番形式のどちらで表示するかの設定
- 模試の途中経過（選んだ答え、残り時間）と、採点結果
- 今日の1問の解答の状態

ブラウザの「サイトのデータを削除」で、いつでも消せます。別の端末や別のブラウザには引き継がれません。

### アクセスの計測

どのページがどれくらい見られているかを知り、内容を良くするために、Cloudflare, Inc. の Cloudflare Web Analytics を使っています。
Cloudflare の説明によると、この計測は Cookie を使わず、利用者を個人として追いかけるための識別子（IP アドレスや端末の特徴など）も使いません。
当サイトが見られるのは、ページごとの表示回数、参照元、国、ブラウザの種類などの、まとめた数字だけです。
サンプル模試を「始めた」「採点した」の回数も、同じ方法で数えています（だれが、どの問題に、どう答えたかは送りません）。

### サイトの配信

当サイトのページは GitHub Pages（GitHub, Inc.）から配信しています。配信のために、GitHub は IP アドレスなどのアクセスの記録を取得します。
当サイトの運営者は、この記録を見ることができません。

## 3. 会員サービスを使うとき

### note で入会した場合

支払いと会員の管理は、note 株式会社のサービス上で行われます。お支払いの情報は note が取り扱い、当サイトは受け取りません。
note の画面で、運営者は会員のクリエイター名などを見ることができます。会員ページに入力した合言葉は、端末の中にだけ保存し、
当サイトのサーバーには送りません。

### 当サイトで入会した場合

【この項は、サイトでの入会（Stripe）を始めるときに公開する。始めるまでは、この項を消しておく】

| 情報 | だれが持つか | 何に使うか |
|---|---|---|
| メールアドレス | Stripe。当サイトの運営者も Stripe の管理画面で見られる | ご本人の確認、ログイン用のメール、お支払いに関する連絡 |
| クレジットカードの情報 | Stripe だけ。**当サイトは受け取らず、保存もしません** | お支払い |
| お支払いの記録（日付、金額、契約の状態） | Stripe。当サイトの運営者も見られる | 会員かどうかの確認、会計、お問い合わせへの対応 |
| メールアドレスから作った照合用の値（ハッシュ）と、契約の状態 | 当サイト（Cloudflare Workers の保存領域） | ログインしたときに、会員かどうかを確かめる |
| ログインの状態を示す Cookie（`td_session`） | お使いのブラウザ。有効期間は30日 | ログインした状態を保つ。広告や追跡には使いません |

- 決済は、ストライプジャパン株式会社（Stripe）のページで行います。Stripe での情報の扱いは、Stripe のプライバシーポリシーによります。
- ログイン用のメールは、【メール送信サービスの名前と会社名】を通じて送ります。そのために、メールアドレスをこの会社に渡します。
- 会員かどうかの確認は、Cloudflare, Inc. の Cloudflare Workers で動かしています。
- これらの会社は、日本の国外（主に米国）で情報を取り扱うことがあります。
- 模試の解答や採点結果は、会員の場合も端末の中にだけ保存し、当サイトのサーバーには送りません。

## 4. お問い合わせ

お問い合わせでいただいたお名前、メールアドレス、内容は、返信と対応のためだけに使います。

## 5. 利用の目的

当サイトが取得した情報は、次の目的のためだけに使います。

1. 会員サービスの提供（ご本人の確認、ログイン、会員向けの内容の提供）
2. お支払いに関する手続きと連絡
3. お問い合わせへの対応
4. サイトの内容の改善（まとめた数字だけを使います）

宣伝のメールは送りません。

## 6. 第三者への提供

次の場合を除いて、利用者の情報を第三者に渡しません。

- ご本人の同意があるとき
- 法令に基づくとき
- 上の 2・3 に書いた、サービスを動かすために必要な会社に取り扱いを任せるとき

## 7. 安全に管理するための取り組み

- クレジットカードの情報を、当サイトは受け取らず、保存しません。
- 当サイトが保存する会員の情報は、メールアドレスそのものではなく、照合用の値（ハッシュ）です。
- 管理画面（Stripe、Cloudflare、GitHub）には、二段階認証を設定しています。【実際に設定してから公開する】
- 情報の取り扱いは、運営者1名だけが行います。

## 8. ご本人からの請求

ご自分の情報について、内容の確認、訂正、利用の停止、削除を希望されるときは、上の連絡先までご連絡ください。
ご本人であることを確かめたうえで、遅滞なく対応します。退会後の削除のご希望も、同じ連絡先で受け付けます
（法令で保存が必要な会計の記録を除きます）。

## 9. このポリシーの変更

内容を変えるときは、このページでお知らせします。大事な変更は、会員ページでもお知らせします。

## 公開前に確かめること

法律の専門家が確認した文面ではありません。

1. **A案（note）だけの間に公開する場合**は、「当サイトで入会した場合」の項を消します。Stripe を始めるときに戻します。
2. **運営者の氏名・住所**：個人情報保護法 32条は、事業者の氏名・住所などを「本人の知り得る状態」に置くことを求めています。
   「本人の求めに応じて遅滞なく回答する」形でもよいとされています。
   - 根拠：個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン（通則編）」の「保有個人データに関する事項の公表等」
     https://www.ppc.go.jp/personalinfo/legal/ （最新版で、該当する箇所を自分で確かめてください。**条文番号と文言は未検証**）
3. **Cloudflare Web Analytics の説明**：「Cookie を使わない」「個人を追いかける識別子を使わない」は、Cloudflare 自身の説明に基づきます
   （Cloudflare の公式ブログ・製品ページ）。公開の前に、その時点の Cloudflare の説明と合っているかを確かめてください。**未検証**。
4. **国外の会社（Stripe、Cloudflare、メール送信サービス）**：国外の会社に個人データの取り扱いを任せる・渡す場合、
   本人の同意や情報の提供が必要になることがあります（個人情報保護法 28条）。どの扱いに当たるかは、**未検証**です。
   - 根拠：個人情報保護委員会「ガイドライン（外国にある第三者への提供編）」https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore
   - 確かめること：Stripe の日本向けの契約の相手がどの会社か、各社のデータ処理の契約（DPA）の内容、メール送信サービスの所在国。
   - 心配なときは、個人情報保護委員会の相談窓口か、専門家に確認してください。
5. **メール送信サービス**：どの会社を使うかを決めてから、3 の【　】を埋めます（`MIGRATION_B.md` の「決めること」）。
6. **二段階認証**：7 に書いたとおりに、実際に設定します。
7. **note の説明**：運営者が note の管理画面で見られる情報が、この文面と合っているかを確かめます。
8. **Cookie**：`td_session` 以外の Cookie を使い始めたとき（広告、別の計測など）は、このページを直します。
9. **GitHub Pages の記録**：GitHub の説明（GitHub Pages のドキュメントの、データの収集に関する項）と合っているかを確かめてください。**未検証**。
