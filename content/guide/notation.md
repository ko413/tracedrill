基本情報技術者試験 科目Bのプログラムは、IPAが定めた「擬似言語の記述形式」で書かれています。このページは、その書き方を1ページにまとめた早見表です。

載せているのは、IPAの問題冊子にある「擬似言語の記述形式」と、公開問題の中で確かめた書き方だけです。問題ごとに注釈で補われることがあるので、本番では必ず問題文も読みます。

## 宣言・代入・注釈

| 書き方 | 意味 | 例 |
|---|---|---|
| `型名: 変数名` | 変数を宣言する | `整数型: i` |
| `型名: 変数名 ← 式` | 宣言と同時に値を入れる | `整数型: sum ← 0` |
| `変数名 ← 式` | 変数に式の値を代入する | `sum ← sum ＋ 1` |
| `/* 注釈 */`、`// 注釈` | 注釈（実行されない） | `// 合計を求める` |
| `大域: 型名: 変数名` | どの手続・関数からも使える変数を宣言する | `大域: 整数型: top ← 0` |

型名には、整数型、実数型、論理型、文字型、文字列型などがあります。配列は `整数型の配列`、二次元配列は `整数型の二次元配列` のように書きます。

## 手続と関数

| 書き方 | 意味 | 例 |
|---|---|---|
| `○手続名(引数, …)` | 手続（値を返さない）を宣言する | `○push(整数型: x)` |
| `○型名: 関数名(引数, …)` | 関数（値を返す）を宣言する | `○整数型: pop()` |
| `手続名又は関数名(引数, …)` | 手続・関数を呼び出す | `push(3)` |
| `return 式` | 関数の戻り値を返して、関数を終える | `return sum` |

## 条件分岐

```
if (条件式1)
  処理1
elseif (条件式2)
  処理2
else
  処理3
endif
```

上から順に条件式を調べ、最初に真になった所の処理だけを実行します。`elseif` と `else` は省くことがあります。

## 繰返し

| 書き方 | 意味 |
|---|---|
| `while (条件式)` … `endwhile` | 前判定。条件式が真の間、処理を繰り返す。最初から偽なら1回も実行しない |
| `do` … `while (条件式)` | 後判定。処理を実行してから条件式を調べる。必ず1回は実行する |
| `for (制御記述)` … `endfor` | 制御記述のとおりに繰り返す |
| `繰返し処理を終了する` | いちばん内側の繰返しを、途中で抜ける |

`for` の制御記述は、日本語で書かれます。

```
for (i を 1 から 5 まで 1 ずつ増やす)
  sum ← sum ＋ i
endfor
```

## 演算子と優先順位

上の行ほど先に計算します。

| 種類 | 演算子 | 補足 |
|---|---|---|
| 式 | `( )`、`.` | かっこ、メンバの参照 |
| 単項演算子 | `not`、`＋`、`－` | 否定、正負の符号 |
| 二項演算子（乗除） | `×`、`÷`、`mod` | `mod` は余り |
| 二項演算子（加減） | `＋`、`－` | |
| 比較 | `≠`、`≦`、`≧`、`＜`、`＝`、`＞` | `＝` は「等しい」。代入は `←` |
| 論理積 | `and` | 両方とも真のとき真 |
| 論理和 | `or` | どちらかが真のとき真 |

- 整数どうしの割り算で商だけを使うときは、`7 ÷ 2 の商` のように書かれます。詳しくは「[「÷」「の商」「の余り」「mod」の読み方](../division/)」をご覧ください。
- 論理型の値は `true` と `false` です。

## 配列

| 書き方 | 意味 | 例 |
|---|---|---|
| `{値, 値, …}` | 配列の内容 | `整数型の配列: data ← {3, 1, 4}` |
| `配列名[要素番号]` | 配列の要素 | `data[2]` |
| `{{値, …}, {値, …}}` | 二次元配列の内容（行ごとにまとめる） | `{{1, 2}, {3, 4}}` |
| `配列名[行番号, 列番号]` | 二次元配列の要素 | `matrix[2, 1]` |
| `配列名の要素数` | 配列の要素の個数 | `dataの要素数` |
| `配列名の末尾 に 式の値 を追加する` | 配列の最後に要素を1つ足す | `outの末尾 に xの値 を追加する` |

要素番号が 1 から始まるか 0 から始まるかは、問題文に書かれています（「配列の要素番号は 1 から始まる」など）。詳しくは「[配列と要素番号](../arrays/)」をご覧ください。

## 未定義

| 書き方 | 意味 | 例 |
|---|---|---|
| `未定義の値` | 値が入っていないことを表す値。代入すると、その変数は未定義になる | `next[p] ← 未定義の値` |
| `変数 が 未定義` | 変数に値が入っていないとき真 | `if (next[p] が 未定義)` |

宣言しただけで値を入れていない変数も、未定義です。リストの末尾（次の要素がない）を表すときなどに使われます。

## 出力

| 書き方 | 意味 | 例 |
|---|---|---|
| `式の値 を出力する` | 式の値を出力する | `nの値 を出力する` |
