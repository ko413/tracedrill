## while：先に調べる

```
while (条件式)
  処理
endwhile
```

条件式が真の間、処理を繰り返します。**先に**条件を調べるので、最初から偽なら処理は1回も実行されません。

## do〜while：あとで調べる

```
do
  処理
while (条件式)
```

処理を実行した**あと**で条件を調べます。処理は必ず1回は実行されます。

## for：回数が決まっている

```
for (i を 1 から n まで 1 ずつ増やす)
  処理
endfor
```

i を 1 から始め、n を超えるまで、1 ずつ増やしながら処理を繰り返します。「まで」は n を含みます。n が 5 なら5回です。

## 回数の数え方

- `for (i を a から b まで 1 ずつ増やす)` は、b − a ＋ 1 回です。
- 条件を調べる回数は、処理の回数より1回多くなります（最後に偽になる回があるため）。
- 始まりの値が終わりの値より大きければ、1回も実行されません。

「減らす」と書かれていれば、大きい値から小さい値へ向かいます。
