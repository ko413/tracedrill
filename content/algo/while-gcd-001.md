## 何をしているか

ユークリッドの互除法です。「a を b で割った余り」を求め、a に b を、b に余りを入れ直すことを、b が 0 になるまで繰り返します。b が 0 になったときの a が最大公約数です。

## トレースのコツ

- 1回の繰返しで3つの代入が続きます。**上から順に1行ずつ**表に書きます。まとめて書くと、古い a と新しい a を取り違えます。
- `r ← a mod b` の時点では、a と b はまだ前の値です。
- 繰返しを続けるかどうかは、3つの代入が終わったあとの b で決まります。

## よくある間違い

- `a ← b` のあとで `b ← r` を計算するとき、b に新しい a を入れてしまう。r は先に求めてあるので、その値をそのまま入れます。
- b が 0 になった回も本体を実行してしまう。while は**先に**条件を調べるので、b が 0 なら本体には入りません。
- 戻り値を b（つまり 0）と答える。返すのは a です。
